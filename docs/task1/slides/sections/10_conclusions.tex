\begin{block}{Design Summary}
\small
\begin{itemize}
    \item Five crews, including an independent Safety Validation crew.
    \item Eight agents with distinct responsibilities.
    \item Eight deterministic tools; two custom: conflict detection (T4) and manoeuvre calculation (T5).
    \item Three routers; retry loop with $N = 2$.
\end{itemize}
\end{block}
\end{column}

\begin{column}{0.49\textwidth}

\small
\begin{itemize}

    \item Pydantic outputs exchanged between crews.
    \item Flow routers A--C and the retry loop.
    \item Test scenarios covering every branch of the flow.
\end{itemize}
\end{block}
\end{column}
