\begin{frame}{Tactical, Safety and Reporting}

\begin{columns}[T,onlytextwidth]

\begin{column}{0.32\textwidth}
\begin{block}{Crew 3: Tactical}
\scriptsize

\textbf{A5: Flight Change Planner}

\vspace{0.15cm}
Tool: T5

\vspace{0.1cm}
Proposes altitude changes, speed changes or departure delays within aircraft limits.

\vspace{0.3cm}

\textbf{A6: Route Planner}

\vspace{0.15cm}
Tool: T6

\vspace{0.1cm}
Finds alternative routes through the airspace network.

\end{block}
\end{column}

\begin{column}{0.32\textwidth}
\begin{block}{Crew 4: Safety}
\scriptsize

\textbf{A7: Safety Checker}

\vspace{0.15cm}
Tools: T4, T7

\vspace{0.2cm}
Independently checks proposed changes for original and secondary conflicts. Marks each proposal as \texttt{VALIDATED} or \texttt{REJECTED}, with a reason.

\end{block}
\end{column}

\begin{column}{0.32\textwidth}
\begin{block}{Crew 5: Reporting}
\scriptsize

\textbf{A8: ATC Reporter}

\vspace{0.15cm}
Tool: T8

\vspace{0.2cm}
Prepares the final report and assigns each flight a status:
\texttt{CLEARED},
\texttt{CLEARED WITH AMENDMENT}
or \texttt{NOT CLEARED}.

\end{block}
\end{column}

\end{columns}

\vspace{0.3cm}

\begin{center}
\footnotesize
\textbf{Why add Crew 4?}

The planner must not validate its own changes.
A proposed fix may create a conflict with another aircraft.
Independent validation provides a separate safety check.

\end{center}

\end{frame}
